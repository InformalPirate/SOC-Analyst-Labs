# SOC Case 007 — PowerShell Activity Investigation

## Case Overview

**Case ID:** SOC-007  
**Investigation Date:** November 2, 2026  
**Category:** Endpoint Security / PowerShell Analysis  
**Classification:** Likely Benign — No Confirmed Compromise  
**Status:** Closed — Training Investigation

This investigation examined PowerShell activity recorded in the Windows PowerShell Operational event log.

The analysis focused on Event ID 4104 script-block records containing Windows Management Instrumentation (WMI) and networking-related PowerShell code.

By examining script contents, timestamps, process identifiers, and parent-process relationships, the investigated activity was assessed as consistent with legitimate Windows networking-management functionality.

No confirmed malicious PowerShell execution was identified.

## Investigation Objectives

- Examine PowerShell Event ID 4104 records.
- Identify potentially suspicious script-block activity.
- Analyze WMI and CIM references.
- Investigate PowerShell process execution context.
- Correlate process and parent-process information.
- Distinguish legitimate activity from potentially malicious execution.
- Document findings and investigation limitations.

## Key Investigation Findings

### 1. PowerShell Event Log Analysis

Confirmed that the PowerShell Operational log was enabled.

At the beginning of the investigation, the log contained 1,957 records.

Among the 100 most recent events, 82 were Event ID 4104 script-block records.

### 2. WMI and CIM Script-Block Analysis

Investigated PowerShell code referencing:

`ROOT/StandardCimv2/MSFT_NetUDPSetting`

Additional networking-related classes included:

- `MSFT_NetUDPEndpoint`
- `MSFT_NetTCPConnection`
- `MSFT_NetIPAddress`
- `MSFT_NetRoute`
- `MSFT_NetIPInterface`

The code referenced Microsoft's `CimCmdletAdapter`, consistent with PowerShell networking-management command definitions.

The `ROOT` namespace reference was identified as part of Windows WMI rather than evidence of elevated privileges.

### 3. PowerShell Process Investigation

Examined PowerShell process ID `16796`.

**Executable:**

`C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe`

**Parent process:**

`C:\WINDOWS\Explorer.EXE`

**Parent PID:** `2860`

Process start times were consistent with Windows Explorer launching the PowerShell session.

### 4. Investigator-Generated Events

Identified several PowerShell script-block records generated by commands executed during the investigation.

This reinforced the importance of distinguishing analyst-generated activity from the original events being investigated.

### 5. Security Assessment

The reviewed script blocks were consistent with legitimate Windows networking-management functionality.

No confirmed evidence of credential theft, unauthorized privilege escalation, or malicious PowerShell execution was identified.

The precise command responsible for loading the networking-related code was not conclusively established.

## Final Assessment

**Classification:** Likely Benign  
**Status:** Closed  
**Confirmed Compromise:** None identified in the reviewed evidence

The available evidence did not establish malicious PowerShell activity.

The investigation was limited to the examined event records and process information, rather than a comprehensive security assessment of the endpoint.
